# Checkpoint release status

No trained weights are included in this candidate. The archived metrics are not a substitute for checkpoints, and an example configuration is not proof that the historical weights can be recreated bit for bit.

If the authors later distribute checkpoints, provide a release manifest containing the probe, dataset version, training lineage, train arm, split seed, fold, final epoch, parameter configuration, actual checksum, and real download location. Do not invent a hash or a placeholder download that looks operational.

Use a separate authorized artifact release for large binaries. Only load serialized checkpoints from trusted sources. The portable launcher's newly generated checkpoints must remain distinguishable from the historical manuscript checkpoints.
